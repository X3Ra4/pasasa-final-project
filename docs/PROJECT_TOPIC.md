# Тема фінального проєкту

**Назва:** PASASA — вебзастосунок для пошуку, створення та оцінювання ігрових локацій ARK: Survival Ascended.

**Предметна область:** каталог ігрових карт і місць для будівництва баз у режимах PvP та PvE.

**Мета:** надати гравцям зручний інструмент для перегляду локацій, порівняння їхніх характеристик, збереження обраного та обміну власними знахідками.

Застосунок містить каталог карт та пов’язаних із ними локацій. Кожна локація має назву, координати, тип і характеристики. Користувач може шукати записи, фільтрувати їх за картою, змінювати порядок сортування, відкривати деталі та інтерактивну карту. Після реєстрації доступні створення, редагування й видалення власних локацій, оцінювання та обране. Адміністратор керує картами, усіма локаціями, довідниками та медіафайлами.

**Основні моделі:** `Map`, `Spot` (PvP), `Place` (PvE), `User`. Додаткові моделі описують типи й особливості локацій, фото/відео та оцінки гравців. Використано ForeignKey і Many-to-Many, валідацію форм, авторизацію та розмежування доступу.

**Технології:** Python 3.12, Django 5.2 LTS, Django Templates, SQLite, HTML, CSS, JavaScript, Pillow.

**Очікуваний результат:** працездатний вебзастосунок із CRUD основних моделей, пошуком, фільтрацією, сортуванням, профілями користувачів і адміністративною панеллю. Проєкт передається у GitHub-репозиторії з інструкціями запуску, тестами та скриншотами.
