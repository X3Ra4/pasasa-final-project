# Тематика фінального проєкту з AWS

**Тема:** «Хмарна платформа PASASA для пошуку та оцінювання ігрових локацій ARK: Survival Ascended на базі AWS EC2».

**Мета:** розгорнути повноцінний вебзастосунок у хмарі AWS, забезпечити постійне збереження даних, фонову роботу, автоматичний запуск після перезавантаження та оновлення з GitHub.

**Предметна область:** ігрові карти ARK і місця для будівництва баз у режимах PvP та PvE. Користувачі переглядають інтерактивні карти, шукають локації, фільтрують їх за картою, додають власні записи, залишають оцінки та формують обране. Адміністратор керує картами, довідниками й контентом.

**Хмарна архітектура:** Django працюватиме на AWS EC2 з Ubuntu 24.04. PostgreSQL буде встановлено на тому ж інстансі та доступно через localhost. Nginx прийматиме вебзапити й передаватиме їх Gunicorn, а статичні та завантажені файли обслуговуватиме з окремих каталогів. Дані зберігатимуться на диску EBS.

**Експлуатація:** Gunicorn запускається як systemd-сервіс pasasa.service із перезапуском при помилці та автозапуском через systemctl enable. Паролі, секретний ключ Django й endpoint PostgreSQL зберігаються у /etc/pasasa/.env та підключаються директивою EnvironmentFile. Код зберігається на GitHub, первинний deploy виконується через git clone, оновлення — через git pull.

**Технології:** AWS EC2, EBS, VPC/Security Groups, Ubuntu, Python, Django, PostgreSQL, Gunicorn, Nginx, systemd, Git/GitHub, HTML/CSS/JavaScript.

**Очікуваний результат:** доступний у браузері хмарний сервіс, що демонструє реальний EC2, БД на сервері, автозапуск, змінні середовища та відтворюваний deploy. Додатково передбачено health endpoint і автоматизовані перевірки.

**Поточний стан:** код і файли розгортання підготовлено у cloud-solutions-aws. Фактичний запуск у AWS та докази роботи EC2 потрібно виконати після надання доступу до інстанса.
