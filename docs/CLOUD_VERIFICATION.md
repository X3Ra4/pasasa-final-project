# Перевірка хмарної гілки

Дата: 14 жовтня 2026. Це результати локальної перевірки, не звіт про запуск в AWS.

| Перевірка | Результат |
| --- | --- |
| Django, Python 3.12 / SQLite | 23 тести пройдено |
| Django, Ubuntu 24.04 / PostgreSQL | 23 тести пройдено |
| Міграції порожньої PostgreSQL | Застосовано всі міграції |
| Повторне seed_demo | Без дублювання даних |
| makemigrations --check --dry-run | Змін моделей немає |
| check --deploy, HTTPS-профіль | Без помилок; W005/W021 — HSTS subdomains/preload навмисно вимкнені |
| Bash + ShellCheck | Скрипти пройшли перевірку |
| systemd-analyze verify | Unit пройшов перевірку синтаксису/залежностей |
| Gunicorn під користувачем pasasa | Запустився на localhost:8001 |
| Nginx → health та каталог | HTTP 200; підключення до PostgreSQL працює |
| Static і media через Nginx | HTTP 200 |

Команди відтворення наведено в README. Перевірка використовує тимчасовий Docker-контейнер без host mounts, відкритих портів чи AWS-ресурсів.

**Ще не перевірено:** запуск на реальному EC2, роботу служби під systemd як PID 1, автозапуск після reboot, AWS Security Group та справжній TLS-сертифікат. Для цього потрібні доступ до EC2 і, для TLS, домен. На цьому етапі не можна стверджувати, що всі вимоги фактичного AWS-розгортання вже виконано.
