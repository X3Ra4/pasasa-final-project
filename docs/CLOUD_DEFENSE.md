# Захист Cloud Solutions

**Стан:** фактичний EC2 ще не розгорнуто; наявні скриншоти показують локальну програму.

## Вступ

«PASASA — хмарна платформа для карт і локацій ARK. Користувачі додають локації, оцінюють їх і зберігають обране. Я підготував розгортання на EC2, PostgreSQL на цьому ж сервері, Nginx і Gunicorn, systemd-автозапуск та конфігурацію через EnvironmentFile. Код оновлюється з окремої гілки GitHub».

Після фактичного запуску замініть «підготував розгортання» на «розгорнув». Локальний контейнер не є AWS-інстансом.

## Що показати після розгортання

1. EC2 у консолі: running, ОС, тип, регіон та Security Group.
2. Реальну адресу сайту: створення й редагування локації, карту, обране.
3. PostgreSQL: `sudo -u postgres psql -d pasasa -c 'SELECT count(*) FROM maps_place;'`.
4. `systemctl is-enabled pasasa`, `systemctl is-active pasasa`, unit з EnvironmentFile.
5. GitHub-гілку та `sudo git -C /opt/pasasa log -1 --oneline` на сервері.
6. `.gitignore` і пояснення секретів; сам `.env` та ключі не показувати.
7. `/healthz/`, журнали й відновлення сервісу після контрольованого reboot.

## Матеріали, які ще потрібно зібрати

- URL і дата перевірки.
- Скриншоти EC2 running та Security Group.
- Сайт з адресним рядком AWS/власного домену.
- Статус systemd, автозапуск і шлях EnvironmentFile.
- Міграції PostgreSQL та збереження створеного запису після рестарту.
- Результат перевірки після reboot.

Додайте матеріали в `screenshots/cloud/` і оновіть README. До фактичної перевірки це план, а не звіт про виконання.
