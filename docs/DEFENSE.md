## Короткі відповіді

- **Чому FlatList?** Віртуалізує довгі списки; стабільні ID — ключі елементів.
- **push чи replace?** push зберігає повернення до каталогу; replace прибирає
  завершену форму чи вступ з поточного місця історії.
- **Як уникнути застарілої відповіді?** AbortController скасовує попередній
  запит; скасований результат не змінює UI; запит має timeout.
- **Що коли запис не вдався?** Черга серіалізує операції. Новий стан
  публікується після setItem; помилка залишає попередні дані та показує повідомлення.
- **Де анімації?** Button: spring scale; Entrance: opacity/translateY;
  Loading: loop opacity; ShoppingRow: opacity після відмітки.
- **Чому рецепти англійською?** Це оригінальні дані API. Переклад не вигадуємо.
- **Чого немає?** Акаунтів і синхронізації; проєкт свідомо зберігає дані локально.
