# Трекер реалізації та дефектів

Журнал нижче містить реально виконані роботи та відтворені дефекти.
GitHub Issues цього репозиторію використовується як зовнішній баг-трекер;
шаблони задач і помилок зберігаються в `.github/ISSUE_TEMPLATE/`.

| ID | Завдання | Критерій приймання | Стан |
|---|---|---|---|
| TF-01 | Авторизація та проєкти | Реєстрація, вхід, CRUD; посторонній не бачить проєкт | Виконано |
| TF-02 | Команда і завдання | Додавання/видалення учасника, призначення, статуси, архів | Виконано |
| TF-03 | Пошук і статистика | Комбіновані фільтри, сортування, коректні підсумки | Виконано |
| TF-04 | REST API | CRUD і коментарі з тими самими правами | Виконано |
| TF-05 | Інтерфейс | Повний браузерний сценарій і мобільна ширина 390 px | Виконано |
| TF-06 | Контейнери та документація | PostgreSQL/Gunicorn/Nginx, перевірки, інструкції | Виконано |

| Bug | Відтворення | Причина | Виправлення / перевірка |
|---|---|---|---|
| TF-B01 | Browsable API показував сторонні username у виборі виконавця | Необмежений queryset пов’язаного поля | Виконавці лише доступного проєкту; regression test |
| TF-B02 | Статус, змінений одночасно з архівуванням, перезаписував архів/призначення | Збереження застарілого об’єкта та перевірка до повторного читання | Спільне блокування проєкту, вузьке збереження статусу; regression і PostgreSQL concurrency tests |
| TF-B03 | Фільтр `assignee=²` спричиняв 500 | `isdigit()` допускав символ, який не перетворюється в int | Обмежений ASCII integer parser; Unicode/довгі/негативні значення в тесті |

Усі три дефекти знайдені незалежним оглядом і виправлені до фінальної публікації.
Докладні команди перевірки: [TEST_REPORT.md](TEST_REPORT.md).
