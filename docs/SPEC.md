# TaskFlow: специфікація

Вебсайт для особистих і командних завдань за погодженим описом.
Frontend: Django Templates, локальний Bootstrap, CSS, JavaScript.
Backend: Django, Django REST Framework; PostgreSQL у Docker, SQLite для швидкого запуску.

Власник створює/редагує/видаляє проєкт, додає зареєстрованих активних учасників за точним username,
керує завданнями, архівує й відновлює їх. Учасники читають проєкт і коментують завдання;
лише призначений виконавець може змінювати статус свого неархівованого завдання.
Видалення учасника прибирає його призначення та доступ. Проєкти приватні.
Адміністратор керує користувачами через Django Admin, доступ до приватних проєктів через сайт
не отримує автоматично. Власник може редагувати коментарі не передбачено: коментарі лише додаються.

Завдання: заголовок, опис, виконавець, пріоритет (low/normal/high), строк, статус
(todo/doing/done), archive flag, timestamps. Коментарі з автором і датою.
Дошка, архів, пошук, фільтри статус/виконавець/пріоритет, сортування строк/дата/пріоритет,
статистика активних/виконаних/прострочених; архів не входить у статистику активної роботи.
REST API із session/token auth, тими ж правами, пагінацією та валідацією.
HTML зміни лише POST із CSRF; жодні GET не змінюють дані.

Завершення: міграції, демодані без спільного пароля, тести ізоляції та CRUD, перевірка браузером,
Compose PostgreSQL+Gunicorn+Nginx, CI, README, посібник користувача, API, розгортання,
тест-звіт, сценарій захисту, task/bug tracker. Не вигадувати учасників, історію Scrum чи публічний сервер.
Контейнерне розгортання покриває додатковий пункт PDF; реальний зовнішній сервер не надано.
