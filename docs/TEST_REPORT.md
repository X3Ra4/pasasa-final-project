## Виправлення за незалежним переглядом

- Чернетка нотатки скидалася після запису обраного/покупок. Стан чернетки
  відокремлено від об'єкта persisted notes. Регресійний E2E спершу відтворив
  проблему, потім пройшов з текстом, набраним **до** інших операцій.
- Поля category/area у пошкодженому сховищі могли бути об'єктами.
  Додано валідацію типів і 3 регресійні перевірки (object/array/number).
- На web додано `aria-checked` до рядків покупок; тест перевіряє фактичний стан.
- Для відтворюваного `npm ci` зафіксовано Reanimated 4.5.1, сумісний із SDK 57,
  замість автоматично підтягнутої несумісної optional peer dependency.

несумісні зміни порушують стек SDK. Проєкт призначено для навчальної здачі;
перед магазинним релізом потрібен окремий перегляд оновлень і залежностей.
