## Що перевіряють тести

- Приватність списків, деталей, API та форм вибору виконавця.
- CRUD власника, обмеження учасника, заборона дій посторонньому.
- Призначення лише активним учасникам; заборона перенесення завдання на інший проєкт.
- Видалення учасника відкликає доступ і прибирає призначення.
- Архів не входить до активної дошки/статистики, відновлення повертає завдання.
- Автор коментаря визначається сервером, HTML екранується, порожній коментар відхиляється.
- CSRF для HTML, відсутність мутацій через GET, токени та блокування неактивного акаунта.
- Фільтри, сортування, підсумки, некоректні Unicode/занадто великі числові параметри.
- Повторне завантаження демоданих зберігає наявні зміни.
- Health endpoint не розкриває деталі помилки БД.
- HTML/API-запит статусу очікує транзакцію архівування або видалення учасника,
  потім повертає 403/404 без перезапису стану.

## Незалежний огляд

Окремий рецензент перевірив код доступу та знайшов три важливі дефекти.
Для кожного відтворено невдалий тест, після виправлення набір став зеленим.
Блокування також перевірені окремими з’єднаннями на реальному PostgreSQL.
Деталі — [TRACKER.md](TRACKER.md).

## Відтворення

```sh
docker compose exec web python manage.py test --verbosity 2
docker compose exec web python manage.py makemigrations --check --dry-run
docker compose exec web python -m pip check
docker compose exec -e DJANGO_HTTPS=1 web python manage.py check --deploy --fail-level WARNING
python tools/http_check.py
```

Браузер: установити `requirements-dev.txt` у venv і Chrome, виконати локальні міграції
та `collectstatic`, запустити `python tools/browser_check.py`.
Він створює тестові акаунти з випадковими паролями; не використовуйте тестову БД як особистий продакшн.

Скриншоти реального запуску збережено у `screenshots/`, усі 5 перевірено візуально.

## Межі перевірки

Перевірене **локальне контейнерне розгортання**, а не AWS чи зовнішній сервер.
Production-check перевіряє конфігурацію HTTPS, але не підтверджує справжній сертифікат,
DNS, зовнішній firewall або reboot віддаленого сервера. Масове навантаження та аудит сторонніх
залежностей у цей звіт не входять. Реальний склад команди/захист не підміняються автоматичними тестами.
